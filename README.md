# User Registration Web Application

## About the Project
This project is a web-based user registration application developed using HTML, JavaScript, Node.js, and Express.js. It allows users to enter their username, email, and password through a registration form.

## Features
- User registration form.
- Username and email input validation.
- Password length validation.
- Client-side form validation.
- Server-side validation using Express.js.
- Registration success and error responses.

## Technologies Used
- HTML5
- JavaScript
- Node.js
- Express.js
- Body-parser

## How to Run
1. Clone the repository.
2. Install Node.js.
3. Install dependencies:
   `npm install express body-parser`
4. Run the server:
   `node server.js`
5. Open `http://localhost:3000` in your browser.
